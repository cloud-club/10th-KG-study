# do-dop

## 소개

- GitHub: [@do-dop](https://github.com/do-dop)
- 스터디 목표:
  - 온톨로지의 개념과 설계 원리 이해
  - 원본 컨텍스트를 파싱하고 구조화된 데이터와 임베딩으로 변환해 데이터베이스에 저장하는 과정 구현
  - 개체(entity)와 관계(relation)를 정의하고 시각화하며, 지식 그래프의 end-to-end 구축 과정 이해
  - 실제 기업 분석 지식 그래프 구축 및 기업, 산업, 인물, 사건 사이의 유기적인 관계 표현
  - 더 정확하고 이해하기 쉬운 지식 그래프를 위한 검색 성능과 지식 표현 방식 개선
