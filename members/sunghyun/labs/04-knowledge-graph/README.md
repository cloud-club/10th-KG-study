# 04. 지식 그래프와 온톨로지

> 관련 노트: [지식 그래프의 배경 — 온톨로지 변천사와 방법론](../../notes/04-knowledge-graph-background.md)

## 목표

문서 검색으로 답하기 어려운 관계 질문을 그래프로 표현하는 방법을 이해한다.

## 학습과 확인한 결과

RDF·OWL·링크드 데이터, 그래프 모델, 기업 사례와 GraphRAG를 학습했다. Wikidata 공개 SPARQL 질의와 결과는 관련 노트에 기록했다.

## 코드

현재 질의 예시는 관련 노트에 있으며, 독립 실행용 코드는 아직 없다. 후속 실습 코드는 `src/`에 기록한다.
