# 샘플 청크 5건

`data/processed/chunks.jsonl`(1,562청크)은 개인 노션 원문이라 커밋하지 않는다.
`chunks.jsonl`의 **구조만** 확인할 수 있도록 5건을 골라 본문을 180자로 자르고
이메일·전화번호를 마스킹해 둔 것이다.

| 필드 | 설명 |
|---|---|
| `id` | `<문서슬러그>#<일련번호>` |
| `source` | 노션 원래 경로 |
| `title` | 문서 제목 |
| `heading` | 문서 안에서의 헤딩 경로 (`A > B > C`) |
| `text` | **1·2세대가 색인하는 값.** `title > heading` 을 본문 앞에 붙인 것 |
| `raw_text` | 헤딩 접두어 없는 순수 본문 |

`text`에 헤딩 경로를 붙여 두는 건 Contextual Retrieval의 값싼 버전이다.
청크가 문서에서 떨어져 나와도 어느 맥락의 조각인지 알 수 있게 한다.
