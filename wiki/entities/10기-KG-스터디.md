- **공용 로컬 인프라** (sese2204, `main`): PostgreSQL 17 + pgvector, ES 9 + nori, Neo4j 5.26 + APOC. 공용 사용 8명, 자체 5명(실습별 상이). 5주차에 Neo4j가 처음 실제로 쓰였다 → [[로컬-인프라]].

- **현황판** (sese2204): `main` 푸시마다 GitHub Pages로 배포, GPT 요약 → [[현황판]].
- **스터디 위키** (2026-09-16, sese2204): dev-docs 개인 위키 방식을 이식. 2026-10-02부터 **매주 월요일 09:00 KST GitHub Actions가 자동 ingest해 PR**로 올린다(`.github/workflows/wiki-ingest.yml`, `scripts/wiki_backlog.py`) → [[LLM-위키-패턴]], [[LLM-위키의-한계와-비판]].
