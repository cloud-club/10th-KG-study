# 읽을거리

주차별로 공부하면서 참고한 자료를 정리한다.

## 1주차

- 「온톨로지 세미나」 PDF — 스터디 전체 흐름과 온톨로지의 개념을 이해하기 위한 자료

## 2주차

- [GNU grep 공식 문서](https://www.gnu.org/software/grep/manual/grep.html) — 문자열과 패턴 검색 방법
- [Elasticsearch nori 분석기](https://www.elastic.co/docs/reference/elasticsearch/plugins/analysis-nori-analyzer) — 한국어 형태소 분석 방법
- [Elasticsearch similarity 설정](https://www.elastic.co/docs/reference/elasticsearch/index-settings/similarity) — BM25를 포함한 관련도 계산 방식
- [pgvector](https://github.com/pgvector/pgvector) — PostgreSQL에서 벡터를 저장하고 검색하는 방법

## 4주차

- [W3C RDF 1.1 Concepts](https://www.w3.org/TR/rdf-concepts/) — RDF 그래프와 트리플의 공식 정의
- [W3C OWL 2 Overview](https://www.w3.org/TR/owl-overview/) — 온톨로지와 OWL의 개요
- [W3C SPARQL 1.1 Overview](https://www.w3.org/TR/sparql11-overview/) — RDF 질의 언어의 공식 개요
- [Google Knowledge Graph](https://blog.google/products-and-platforms/products/search/introducing-knowledge-graph-things-not/) — 검색에서 엔티티와 관계를 활용한 사례
- [Amazon AutoKnow](https://assets.amazon.science/f7/d5/1c452719458b8803d1e397afd535/autoknow-self-driving-knowledge-collection-for-products-of-thousands-of-types.pdf) — 상품 지식 그래프 자동 구축 연구
- [Apple Open-domain Knowledge Graphs](https://machinelearning.apple.com/research/open-domain-knowledgegraphs) — 대규모 지식 그래프 구축과 활용 사례
