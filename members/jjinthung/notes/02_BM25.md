# BM25 + Vector + GPT RAG

## 실행 구조

```text
Talk_*.txt
  -> 청크 생성
  -> Elasticsearch Nori BM25 + Vector 검색
  -> RRF top-5
  -> GPT 답변 생성
```

기본 진입점은 `labs/main.py`다. 기본값으로 검색 결과 top-5를 GPT에
전달하고, 근거에 없는 내용은 답하지 않도록 프롬프트를 적용한다.
GPT 시스템 프롬프트는 `labs/04-generate/system_prompt.txt`에서 관리한다.
프롬프트를 수정하면 다음 실행부터 바로 반영된다.

```powershell
$env:OPENAI_API_KEY="새로 발급한 키"
python -m pip install -r labs\requirements.txt
python labs\main.py "가장 최근에 먹은 음식은?" --top-k 5
```

GPT를 호출하지 않고 검색 결과만 확인하려면:

```powershell
python labs\main.py "가장 최근에 먹은 음식은?" --top-k 5 --retrieve-only
```

모델은 `OPENAI_MODEL` 환경변수 또는 `--model` 옵션으로 변경할 수 있다.
기본 모델은 `gpt-4o-mini`다. API 키는 소스 코드나 문서에 저장하지 않는다.

## 보안

API 키가 채팅, 로그, 코드 등에 노출되면 즉시 OpenAI 대시보드에서 폐기하고
새 키를 발급한다. 새 키는 PowerShell 환경변수로만 등록한다.
