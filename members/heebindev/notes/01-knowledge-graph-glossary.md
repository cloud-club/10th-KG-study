# 1. 지식 그래프 기초 용어

아직 용어에 대해 잘 모르므로 간단한 용어 정리부터 하겠다.

### 문서 (Document)
검색 대상이 되는 하나의 글이다.
나는 학과 전공수업을 정리한 노션을 사용할 것이다.

### 청크 (Chunk)
긴 문서를 한 번에 검색하기는 어렵다. 청크는 이를 적당한 크기로 나눈 텍스트 조각이다.
문서 전체를 그대로 검색하면 여러 주제가 섞일 수 있기 때문에, 여러 청크로 나눈다.

### 청킹 (Chunking)
문서를 여러 청크로 나누는 작업이다.

### 지식 그래프 (Knowledge Graph)
현실 세계의 대상과 그 관계를 그래프 형태로 표현한 데이터 구조다.

희빈 -- 참여한다 --> Cloud Club
희빈 -- 공부한다 --> Knowledge Graph

이처럼 주어, 술어, 목적어의 세 가지 요소로 구분하여 정보를 대상과 관계로 나누어 저장한다.

### 트리플
하나의 사실을 세 가지 요소로 표현한 것이다.

주어 -- 술어 -- 목적어


### 엔티티 (Entity)
구분할 수 있는 현실의 대상이나 개념을 의미한다.

### 온톨로지
특정 분야에 어떤 개념이 존재하고, 그 개념들이 어떤 관계를 가지는지를 정의한 체계다.

지식 그래프는 실제 엔티티와 관계를 저장한 데이터다.
온톨로지는 그 데이터에 어떤 개념과 관계를 사용할지 정의하는 의미 체계다.

### RDF
Resource Description Framework의 약자다.
정보를 주어, 술어, 목적어로 구성된 트리플 형태로 표현하는 표준이다.

### SPARQL
RDF 형태로 저장된 지식 그래프를 조회하기 위한 질의 언어다.
관계형 데이터베이스에서 SQL을 사용하는 것처럼, RDF 데이터에서는 SPARQL을 사용한다.

### 다중 홉 질문(Multi-hop Question)
답을 구하기 위해 두 개 이상의 관계를 연속해서 따라가야 하는 질문이다.

희빈이 참여한 스터디에서 사용하는 데이터베이스는 무엇인가?
희빈 → 참여한다 → KG 스터디
KG 스터디 → 사용한다 → PostgreSQL

### RAG
RAG는 Retrieval-Augmented Generation, 한국어로는 검색 증강 생성이라고 한다.
LLM이 자신의 학습 데이터만 이용해 답변하지 않고, 질문과 관련된 외부 문서를 먼저 검색한 다음 검색 결과를 참고해 답변을 생성하는 방식이다.
