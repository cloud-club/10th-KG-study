## 갈리는 지점

- **인프라**: 공용 compose(sese2204, do-dop, kdyann, heebindev, ur2e, sdunge, Yeongeunn, e0ng 05) vs 자체 compose(dldusgh318, e0ng 02·03, yujeong430, lys0611, sunghyun). 실습 단위로 다르다. 자체 쪽은 포트·버전이 공용과 어긋나 데이터를 그대로 못 옮긴다 → [[로컬-인프라]]. Neo4j 실사용은 5주차 다섯 멤버가 처음.
- **임베딩**: 로컬 bge-m3/KURE/qwen3 1024d(6명) / 로컬 e5-small·ko-sroberta·MiniLM 384~768d(6명) / 외부 API(ur2e, 합성 데이터) / 없음(sdunge). 개인 데이터를 다루는 멤버는 전부 로컬 → [[임베딩-모델-선택]].
- **추출·생성 LLM**: 추출은 다섯 멤버 전원 외부 API(OpenAI 넷, Gemini 하나). 생성은 로컬(lys0611 exaone, do-dop exaone, sunghyun qwen2.5) vs 외부(heebindev gpt-5-mini, kdyann gpt-4.1-mini, jjinthung gpt-4o-mini, sdunge Claude, Yeongeunn Gemini, yujeong430 OpenAI, sunghyun GLM). 개인 대화는 로컬, 공개·문서 데이터는 외부라는 경향이 있지만 예외가 많다 → [[생성-모델-선택]], [[개인-데이터-가명화와-공개-범위]].
- **청킹**: 발화자 섞는 세션(30분: sese2204, lys0611 / 4시간: jjinthung) vs 같은 발신자 연속(1분: do-dop / 5분: e0ng) vs 날짜별(yujeong430) vs 문서 구조(heebindev, ur2e, dldusgh318, sunghyun) vs 고정 문자(sdunge 500/100, Yeongeunn 1,200/200, e0ng 03 1,000/0, do-dop 03 800+문단) vs 없음(kdyann 캡션) → [[청킹-전략]].
- **검색 단위·질의 통일**: 2주차 모순([[검색의-세-세대]])은 3주차 평가에서 yujeong430·Yeongeunn이 4조건(같은 질문·판정·k·청크 집합)을 고정하며 해소 방향.
- **융합 방식**: RRF k=60이 아홉 멤버 공통, 점수 정규화 융합은 do-dop만 구현·비교. k를 바꿔 본 멤버는 lys0611·do-dop 둘 → [[하이브리드-검색과-RRF]].
- **평가 라벨을 누가 붙였나**: 사람 단독(dldusgh318, lys0611, kdyann, sunghyun, yujeong430, heebindev 초안) / LLM 후보 + 사람 확정(e0ng 10문항) / LLM-as-a-Judge(e0ng 36문항) / AI 보조 초안(Yeongeunn) / 없음. 이 축 없이 Recall을 나란히 읽을 수 없다 → [[RAG-평가-지표]].
- **평가셋 공개 가능성**: sunghyun(회사)·lys0611·yujeong430(개인 카톡)·Yeongeunn(팀 설계 문서)은 공유 불가. heebindev·sdunge·do-dop·e0ng·kdyann은 상대적으로 열림.
- **도달 단계**: RRF까지 10명, RAG 생성까지 10명, 정답 라벨 Recall까지 9명, 그래프 구축까지 5명(dldusgh318·e0ng·heebindev·kdyann·Yeongeunn), 그래프를 리트리버로 연결(GraphRAG)은 0명.
- **그래프 저장소**: 다섯 명 전원 PostgreSQL 1차 + Turtle 산출 + Neo4j 탐색. Triplestore 0명. 중간 노드(dldusgh318)와 리터럴 속성(나머지)이 갈리고, 전체 코퍼스 추출을 완주한 멤버는 없다 → [[그래프-적재-Postgres와-Neo4j]], [[폐쇄-스키마-설계]].
- **재현성**: kdyann(합성 예제 + unittest, 외부 API·DB 없이 재현) vs Yeongeunn(검토 파일·qrels git 제외, 해시 불일치 시 중단) vs sunghyun(비공개 데이터·DB·모델 없어 재실행 불가) vs jjinthung(Windows 절대경로 하드코딩).

## 공용 인프라로 모으려면

- 자체 compose 데이터는 `pg_dump`나 재적재가 필요하다(lys0611이 명시). 공용 인스턴스에서는 테이블·인덱스·Neo4j 라벨에 멤버 접두사를 붙인다(do-dop, ur2e, Yeongeunn `yeongeunn_`·`KGStudyYeongeunn`, kdyann `W5_FACT`).
- 같은 골든셋으로 비교하려면 질문 **유형**과 라벨링 **절차**를 공용화하는 게 먼저다 → [[RAG-평가-지표]] 열린 질문. 멤버 그래프를 합치려면 공통 Vocabulary·Entity Resolution이 먼저다 → [[시맨틱-웹에서-지식그래프까지]], [[엔티티-신원해소]].
