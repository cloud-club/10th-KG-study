# 검색 평가셋

`retrieval_gold.json`은 카카오톡 메시지 청크 814개를 대상으로 만든 수동 검색 평가셋이다. 질문마다 원문을 읽어, 그 질문에 답하는 데 직접 필요한 청크 ID를 `relevant_ids`로 표시했다.

## 구성 원칙

- 동일한 질문과 동일한 관련 청크 목록으로 BM25·벡터·RRF 하이브리드를 비교한다.
- 같은 공지가 반복 전송된 경우, 질문에 직접 답하는 반복 공지는 모두 관련 문서로 표시한다.
- 단순히 단어가 포함된 청크가 아니라, 질문의 답을 실제로 담은 청크만 관련 문서로 표시한다.
- 관련 문서가 상위 `k`개 안에 하나도 없으면 Recall@k는 0이다.

Recall@k는 상위 `k`개 결과에서 회수한 관련 청크 수를 전체 관련 청크 수로 나눈 값이다. 예를 들어 답에 필요한 청크가 2개이고, 상위 3개 안에서 1개만 찾으면 Recall@3은 0.5이다.

## 질문 유형

| 유형 | 뜻 | 예시 |
| --- | --- | --- |
| `lexical_exact` | 공지에 나온 명칭을 그대로 사용 | `멋쟁이사자처럼 14기 서류 모집 마감` |
| `lexical_variant` | 조사·어순·표기가 달라짐 | `졸업생 학위복 대여 장소` |
| `semantic_paraphrase` | 원문 명칭 없이 자연어로 바꿔 묻기 | `2학기부터 공결을 종이 말고 어디에서 신청해?` |
| `detail_constraint` | 자격·마감·장소 등 세부 조건 묻기 | `독감으로 통원 치료하면 출석 인정이 되나?` |
| `temporal_disambiguation` | 같은 주제의 다른 학기·시점 공지와 구별 | `2학기 사물함 신청 마감은 언제야?` |
| `multi_evidence` | 답에 두 개 이상 청크가 함께 필요한 질문 | `1차 과잠 신청 기간과 2차 과잠 배부 기간` |

`retrieval_gold.json`은 총 40문항이다. 정확 명칭·형태 변형·자연어 바꿔 말하기·세부 조건뿐 아니라, 비슷한 1학기/2학기 공지를 구별하는 질문과 여러 공지를 함께 찾아야 하는 질문을 포함한다. 따라서 결과는 전체 평균과 함께 질문 유형별 결과를 같이 확인한다.

`answerability_challenges.json`은 답변 근거성 점검용 5문항이다. 질문에 답하는 청크가 없거나 핵심 사실이 원문에 없는 경우이므로 Recall@k 평균에는 넣지 않는다. 이 질문에서는 에이전트가 추측하지 않고 확인 불가라고 답하는지를 수동으로 점검한다.

`rag_limitations.md`에는 실제 다중 홉 관계 질문과 여러 근거를 결합하는 질문을 던졌을 때의 한계를 기록했다.

## 40문항 평가 결과

2026-09-16에 `recall_results.json`을 생성해 측정한 결과다. 하이브리드 검색은 BM25와 벡터 검색에서 각각 상위 20개를 가져온 뒤 RRF(`rank_constant=60`)로 결합했다.

| 지표 | BM25 | 벡터 검색 | 하이브리드 RRF |
| --- | ---: | ---: | ---: |
| Recall@1 | **58.8%** | 45.0% | 57.5% |
| Recall@3 | **88.8%** | 83.8% | 86.2% |
| Recall@5 | **95.0%** | 85.0% | 88.8% |

### 질문 유형별 Recall@3

| 유형 | 문항 수 | BM25 | 벡터 검색 | 하이브리드 RRF |
| --- | ---: | ---: | ---: | ---: |
| 정확 키워드 | 5 | 100.0% | 100.0% | 100.0% |
| 형태 변형 | 6 | 91.7% | 91.7% | **100.0%** |
| 의미 바꿔 말하기 | 13 | **88.5%** | 76.9% | 80.8% |
| 세부 조건 | 7 | 100.0% | 100.0% | 100.0% |
| 시점 구분 | 7 | 71.4% | 71.4% | 71.4% |
| 다중 근거 | 2 | **75.0%** | 50.0% | 50.0% |

### 해석

- 이 40문항에서는 BM25가 전체 Recall@1·3·5에서 가장 높았다. 따라서 하이브리드 RRF가 항상 단일 검색기보다 우수하다고 말할 수는 없다.
- 하이브리드 RRF는 형태 변형 질문에서 Recall@3 100.0%로 가장 높았다. 두 검색기의 결과가 보완될 때 순위 융합이 도움이 된 사례다.
- 의미 바꿔 말하기 질문에서도 BM25가 가장 높았다. 이 데이터에서는 공지의 핵심어가 질문에 비교적 많이 남아 있었고, 한국어 형태소 기반 키워드 검색이 강하게 작동한 것으로 해석할 수 있다.
- 다중 근거 질문은 가장 어려운 유형이다. 답에 필요한 청크가 둘 이상이므로 하나만 상위 결과에 있어도 답변은 불완전해질 수 있다. 이 평가는 관계를 따라가는 다중 홉 검색이 아니라, 여러 근거 청크를 한 번의 검색 결과에서 함께 회수하는지 측정한 것이다.
- 유형별 문항 수, 특히 다중 근거 2문항은 작다. 따라서 유형별 수치는 일반적인 성능 보장이 아니라 현재 데이터와 라벨링한 질문 목록에서의 관찰 결과로 해석한다.

## 실행

```powershell
python src/evaluate_recall.py --output data/evaluation/recall_results.json
```

기본값은 Recall@1·3·5를 모두 출력한다. 전체 평균과 질문 유형별 평균을 함께 출력한다. `recall_results.json`은 실행 결과 파일이며, `retrieval_gold.json`을 수정하면 다시 생성해야 한다.
