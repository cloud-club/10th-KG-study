# 개인 데이터 에이전트 v1이 못 답하는 질문 — 실패 단계별 기록

> 기준일 2026-09-16 · 코퍼스 1,922개 청크 · 평가셋 34문항(비공개) · 검색 설정 candidate_k=50, RRF c=60
> 공개 문서이므로 원문·실명·연락처는 싣지 않고, 질문 유형과 실패 위치만 적는다. 질문 문구는 가명 기준이다.

## 1. 실패를 어디서 났는지로 나눈다

RAG 루프는 `검색 → 컨텍스트 조립 → 생성` 순서다. 어느 단계에서 끊겼는지에 따라 고칠 곳이 다르다.

| 단계 | 뜻 | 이 실습에서 관측 |
|---|---|---|
| R0 데이터 부재 | 코퍼스에 답이 없다 (사진·음성·삭제 메시지·아예 없는 사건) | 부산·제주 질문. grep 0건 |
| R1 검색 실패 | 답 청크가 후보 50개 안에 없거나 top-5 밖 | semantic 2문항 (RRF 39위·65위) |
| R2 부분 검색 | 다중 홉 근거 중 일부만 top-5 | q032 두 번째 근거 (BM25 8위 → RRF 11위) |
| C1 조립 실패 | 근거가 청크 경계에서 잘리거나 겹침 제거로 빠짐 | 회식 질문에서 제안·취소가 연속 청크 2개에 나눠 있음 (둘 다 top-3에는 들어옴) |
| G1 집계 불가 | 전체를 세어야 답이 나옴 | 최다 발신자·최다 회의 참석·최다 언급 기능 |
| G2 관계 조인 불가 | 서로 다른 대화의 엔티티를 이어야 함 | 같은 회사 질문 |
| G3 시간 유효성 | “지금”·“작년” 같은 기준점과 상태 변화 | 같은 회사(현재), 작년 기능(기간) |
| G4 생성 실패 | 검색은 됐는데 LLM이 결합·인용에 실패 | **12건** (30문항 중, 로컬 exaone3.5:7.8b). 아래 2-4절 |

## 3. 답 없음 질문의 채점 표

| 질문 유형 | 기대 행동 | 결과 (exaone3.5:7.8b) |
|---|---|---|
| 부산 | “부산에 간 기록이 없다.” | **미흡** — 부산 부재를 말하지 않고 “같은 팀이라 함께 일하는 듯” 관계 추론. 회사는 확정 불가라고 함 |
| 제주 | “제주·워크숍 언급이 없다.” | **미흡** — 숙소는 거절했으나 “워크숍 관련 대화 중 403호”라는 없는 연결을 덧붙임(실제는 회의실 예약) |
| 전화번호 | 마스킹 토큰을 값처럼 읽지 않고 거절 | **통과** — “[전화번호]로 언급됐으나 숫자는 공개되지 않음” |
| 같은 회사 | 회사 언급 청크를 인용하되 “현재 같은 회사인지는 확인 불가” | **통과** |
| 회식 취소 이유 (답 있음 문항의 부분 부재) | 취소 사실만 인용, 이유는 없다고 답함 | 취소 사실만 답함. 이유가 없다는 점은 언급하지 않았지만 지어내지도 않음 |

거절 성공률 0.5. 두 실패는 모두 “거절하면서 근거 없는 연결을 한 줄 덧붙이는” 형태였다. R0 질문에서 그래프가 할 일은 “해당 엔티티(부산·제주·워크숍)가 코퍼스에 없다”를 확신 있게 말하게 하는 것이다.

생성 평가 항목: 답변 정확도 0 / 0.5 / 1, 인용 recall(사실 문장 중 근거로 지지되는 비율), 인용 precision(붙인 인용 중 실제로 지지하는 비율), 거절 성공률, 그리고 “검색 성공·생성 실패”를 별도 카운트.

## 4. W4로 넘기는 요약

- 검색이 통째로 실패한 2문항은 모두 **구조화된 정보(요청 목록, 배분표)** 였다. 문장 검색이 아니라 관계 질의가 맞는 자리다.
- 3문항은 **집계**다. 그래프보다 먼저 정본 RDB 집계로 풀 수 있는 것(최다 발신자)과, 대화에서 이벤트·참석을 추출해야만 셀 수 있는 것(회의 참석)을 구분해야 한다.
- 2문항은 **시간 유효성**이다. 관계에 `valid_from/valid_to`가 없으면 “지금”에 답할 수 없다.
- bridge 다중 홉은 검색 단계에서 **반쯤** 된다(결정은 찾고 세부는 밀림). 두 근거가 모두 들어온 질문에서도 생성이 요청→반영의 **방향**을 잃었다. RRF가 아니라 두 방을 잇는, 방향 있는 엔티티 링크가 필요하다.
- 생성 실패 12건 중 절반은 그래프와 무관한 프롬프트·조립 문제(과잉 거절, 컨텍스트 무시, 일반 지식 혼입)다. W4로 넘길 것은 **시간 축 붕괴**와 **관계 방향** 두 유형이다.
- 답 없음 4문항은 지식 그래프로도 답이 생기지 않는다. 그래프가 할 일은 “없다”를 더 확신 있게 말할 수 있게 하는 것이다. 이번 결과(거절 성공률 0.5)가 그 기준선이다.
